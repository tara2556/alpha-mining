# alpha-mining

台股研究工作台：用公式描述交易訊號（alpha），評估預測力，轉成策略回測，並在類似
TradingView 的 K 線介面上檢視結果。支援現貨（如 0050、個股）與台指選擇權（買方方向性）。

設計原則：

- **不偷看未來**：訊號在第 t 日收盤後產生、第 t+1 日開盤成交；所有公式函數只用當天（含）以前的資料，
  並以測試逐一驗證。
- **帳可以對**：會計以 `Decimal` 計算，每天核對「現金 + 股數 × 收盤價 = 淨值」。
- **資料可追溯**：保留原始回應與 SHA-256；清理後資料與回測報告都記錄來源與雜湊。
- **不悄悄出錯**：引擎還不會處理的公司行動（配股、減資、反分割）會讓匯入直接停止。

## 安裝與啟動

需要 Python 3.12+，執行期只用標準函式庫（Windows 若缺時區資料需 `pip install tzdata`）。

```powershell
$env:PYTHONPATH = "src"
python -m finback                       # 開啟工作台 http://127.0.0.1:8050/
```

第一次使用時在工作台按「＋ 下載」從 FinMind 抓日線，或用指令：

```powershell
python -m finback.finmind 0050 --start 2020-01-01 --end 2025-12-31
```

FinMind 免 token 即可使用但有流量上限；設定環境變數 `FINMIND_TOKEN` 可提高上限（token 不會寫入任何檔案）。

## 使用工作台

```powershell
$env:PYTHONPATH = "src"
python -m finback                  # 啟動並自動開瀏覽器；--port 改埠號、--no-browser 不開瀏覽器
```

伺服器只綁定本機 `127.0.0.1`，關掉終端機（Ctrl+C）即停止。

### 畫面配置

```text
┌ 頂列：資料集 ▾ ＋下載 │ 期間 起～迄 │ 樣本外起點 │ 已存報告 → ┐
├ Alpha 池 ┬ K 線圖（價格＋成交量）                 ┬ 右側面板    ┤
│ 每張卡片 │ alpha 窗格（門檻虛線）                 │ 公式        │
│ 一條公式 │ 淨值窗格（策略 vs 買入持有）           │ 策略回測    │
│ IC 樣本內│ 縱向虛線 = 樣本外起點                  │ 選擇權      │
└──────────┴────────────────────────────────────────┴─────────────┘
```

窄螢幕（約 1000 px 以下）時 Alpha 池移到圖表下方；手機寬度依序為圖表 → Alpha 池 → 面板。

### 一般流程（以 0050 為例）

1. **取得資料**：頂列按「＋ 下載」，類型選「股票／ETF 日線」，輸入代號（如 `0050`）與起迄日，按「下載」。
   完成後資料會出現在「資料」選單。已下載過的資料不必重抓。
2. **設定期間與樣本外**：「期間」決定圖表與回測範圍；「樣本外起點」那天（含）之後是樣本外，
   調參時不要看它。圖上會以縱向虛線標出。
3. **寫公式（「公式」頁）**：
   - 點左側 Alpha 池的卡片載入既有公式，或按「＋ 新公式」從空白開始。
   - 在「公式」欄輸入，例如 `ts_mean(close, 20) / ts_mean(close, 60) - 1`；按 `Ctrl+Enter` 或「評估」。
   - 下方「預測力」表列出 1／5／20 日的 IC、Rank IC、勝率（樣本內／樣本外並列），「分組報酬」看
     alpha 由低到高分組後的平均未來報酬。可用的函數與變數在「函數與變數」展開區。
   - 滿意就填「名稱」「說明」按「存入池」（寫入 `configs/alphas.json`）；「刪除」移除目前這條。
   - 「全部評估」一次計算池內所有公式，卡片右上角顯示樣本內／樣本外的 5 日 IC。
4. **回測（「策略回測」頁）**：
   - 「策略類型」選「alpha 門檻」就會用「公式」頁目前的公式：alpha > 進場門檻持有、< 出場門檻空手，
     「持股比例」決定持有時投入多少淨值；也可改選均線交叉、動能、固定比例再平衡、買入持有。
   - 「資金與成本」展開後可調本金、交易單位、手續費率／折扣／最低手續費、賣出交易稅。
   - 按「執行回測」：圖上淺色底帶是持倉期間（放大到約 250 根 K 線以內才顯示每筆買賣箭頭），
     淨值窗格比較策略與買入持有；右側表格分樣本內／外列出報酬、波動、Sharpe、回撤、曝險與成本。
   - 「成交紀錄」點一列，圖表會跳到那一天。
   - 要保留結果：填「報告名稱」按「另存報告」，之後在「已存報告 →」（`/reports`）查看。
5. **看報告（`/reports`）**：右上角選報告，看績效摘要、淨值、回撤、曝險、每日帳本（可只顯示有交易／股息的日子）與執行參數。

### 台指選擇權

1. 「＋ 下載」類型選「台指選擇權（含加權指數）」，填起迄日下載（按月抓取，中斷後重按會接續）。
2. 「資料」選單切到台指選擇權後，圖表改為加權指數；「公式」頁的 alpha 以加權指數計算。
3. 「選擇權」頁設定進場規則（偏多／偏空的進出場門檻、偏空時是否買賣權）、契約選擇（月選或含週選、
   價外檔數、最短到期天數、換月天數）與資金成本，按「執行選擇權回測」。
4. 圖上標出每次進出的契約（如 `C22600`、`P21500`）；「成交紀錄」點一列或點圖上任一天，
   下方「契約鏈」顯示當天各履約價的買權／賣權收盤與成交量（淺底為價內）。

### 網址捷徑

- `http://127.0.0.1:8050/#run`：開啟後直接用預設公式跑一次 0050 回測。
- `http://127.0.0.1:8050/#options`：開啟台指選擇權資料並跑一次預設選擇權回測。
- `http://127.0.0.1:8050/reports#<報告名稱>`：直接開某份報告。

### 介面說明

- **K 線圖**：TradingView 開源的 [Lightweight Charts](https://github.com/tradingview/lightweight-charts)
  （Apache-2.0，已放在 `src/finback/web/vendor/`，離線可用）。台股慣例紅漲綠跌；價格做分割調整（僅顯示用），
  圖上標出除息（息）、分割、樣本外起點與持倉期間。窗格：價格與成交量／alpha／淨值（策略 vs 買入持有）。
  滑鼠滾輪縮放、拖曳平移，十字線所在日期的開高低收顯示在左上圖例。
- **Alpha 池**（`configs/alphas.json`）：每個 alpha 是一條公式，例如
  `ts_mean(close, 20) / ts_mean(close, 60) - 1`，可引用池內其他 alpha 的名稱。
  公式以白名單語法解析，不執行任意程式碼。函數清單在介面的「函數與變數」。
- **評估**：IC、Rank IC、勝率、分組報酬，預測期 1／5／20 日。樣本內／樣本外分開計算；
  分組界線只用樣本內資料，樣本內也排除報酬區間跨進樣本外的資料。
- **策略回測**：alpha 門檻（> 進場門檻買進、< 出場門檻賣出）或內建策略，成本、本金、交易單位可調；
  結果分樣本內／外並與買入持有比較，可另存成報告（`/reports` 頁面檢視）。

**避免過度擬合**：調整公式與門檻時只看樣本內；樣本外留到最後檢驗，看過越多次就越不「外」。

## 台指選擇權（買方方向性）

```powershell
python -m finback.options_data --start 2025-01-01 --end 2025-12-31   # 或工作台「＋ 下載」選台指選擇權
```

資料選單選「TAIEX · 台指選擇權」後，「公式」頁的 alpha 會以加權指數計算，「選擇權」頁執行回測：

- **方向**：alpha > 偏多進場買買權、< 偏空進場買賣權，各有出場門檻（遲滯）；只做買方，最大損失為權利金加成本。
- **選約**：第 t 日收盤後，只用當天資訊選「到期日距成交日至少 N 天」中最近的契約（可選只用月選或含週選），
  履約價取最接近加權收盤的價平檔，可往價外移幾檔。
- **成交**：第 t+1 日以該契約**日盤開盤價**成交；開盤價為 0 或無成交量就記為「未成交」，隔天重試，不會用收盤價代替。
- **換月與到期**：到期前 N 天換月；持有到期則現金結算內含價值。結算價以到期日加權指數收盤**近似**
  （官方為收盤前 30 分鐘平均，FinMind 無此資料）。
- **成本**：每口單邊手續費與交易稅率（權利金與結算金額）皆為可調假設。
- **到期日**：依交易所規則推算（月選第三個週三、`Wn` 第 n 個週三、`Fn` 第 n 個週五，遇假日順延），
  並與資料中契約最後交易日逐一核對，不符就停止。
- **契約鏈**：點圖上任一天或交易紀錄，可看當天各履約價的買權／賣權收盤與成交量。

資料只有日盤日線：無盤中價格、無夜盤、無買賣價差，結果會比實際交易樂觀。

## 用設定檔批次回測

```powershell
python -m finback.backtest configs/strategies/0050_trend_2020_2025.json
```

設定檔指定商品、期間、本金、成本與多個策略，結果寫到 `reports/<name>/`（每日帳本、成交明細、`run.json`）。

| type | 參數 | 規則 |
|---|---|---|
| `alpha` | `expr`, `entry`, `exit`, `weight` | alpha > entry 持有、< exit 空手；可用 alpha 池中的名稱 |
| `buy_and_hold` | `weight` | 首日開盤買入後不再交易 |
| `fixed_weight` | `weight`, `period`（month/quarter） | 每期第一個交易日收盤後再平衡 |
| `sma_cross` | `fast`, `slow`, `weight` | 快線 > 慢線持有，否則空手 |
| `momentum` | `lookback`, `weight` | 收盤高於 N 日前收盤時持有 |

新增策略：在 [strategies.py](src/finback/strategies.py) 寫一個有 `target_weight(history) -> Decimal | None`
的類別並登記到 `STRATEGIES`（回傳 `None` 表示不動，0~1 表示隔日開盤調整到該比例）。

## 回測假設

- **成本**：手續費 = max(成交金額 × 費率 × 折扣, 最低手續費)，賣出另收交易稅，皆無條件捨去至元。
  預設法定上限 0.1425%、最低 20 元；交易稅 ETF 0.1%、一般股票 0.3%。皆為輸入假設，非券商報價。
- **公司行動**：現金股利於除息日入帳（給除息前已持有的股數），整數分割於開盤前調整股數。
- **訊號用價格**：以前向還原（只用過去事件）的含息價格計算，分割與除息不會變成假跌幅。
- **尚未模擬**：滑價、漲跌停與成交量限制、現金利息、期末賣出成本、股利再投入。

## 專案結構

```text
src/finback/
  alpha.py        # alpha 公式語言、前向還原價、預測力評估
  engine.py       # 回測引擎（訊號、成交、成本、分割與股利）
  strategies.py   # 內建策略與 alpha 門檻策略
  prices.py       # 日線資料列、帳本快照、共用統計
  finmind.py      # FinMind 下載與公司行動檢查
  options_data.py # 台指選擇權契約鏈下載、到期日規則、資料讀取
  options_engine.py # 選擇權買方回測引擎
  workbench.py    # 工作台 API（資料、alpha 池、評估、回測）
  dashboard.py    # 本機伺服器（只綁定 127.0.0.1）
  backtest.py     # 設定檔批次回測 CLI
  domain/         # 商品、訂單、成交模型（期貨／選擇權共用）
  portfolio/      # 現金、部位與損益
  web/            # 工作台與報告頁前端；vendor/ 為 Lightweight Charts
configs/          # alpha 池與策略設定
tests/            # 單元測試（不需網路）
data/, reports/   # 本機資料與結果，不進版控
```
