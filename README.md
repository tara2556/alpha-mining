# finback-tw

以台灣股票、期貨與選擇權為主的研究型回測系統。目標不是只產生一條績效曲線，
而是讓資料版本、商品規格、訊號、成交假設、交易成本與結果都能被重現及檢查。

## 設計原則

- 所有市場時間都必須帶時區，預設使用 `Asia/Taipei`。
- 商品乘數、最小跳動、交易成本與保證金由設定或歷史資料提供，不硬寫在策略內。
- 訊號時間、送單時間與成交時間分開，降低未來函數風險。
- 原始資料不可覆寫；清理後資料需保留來源及版本資訊。
- 選擇權以契約鏈與多腿部位建模，而不是視為沒有到期日的一般 K 線。

## 目前範圍

第一個核心切片已包含商品、K 線、訂單、成交、現金部位與逐筆盯市模型。
費率、保證金、撮合規則及資料供應商會在下一階段接到這些穩定介面上。

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```
